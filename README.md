# portal

Корпоративный портал DOGMA VPN: выдача подписок, маршрутизация,
поддержка и администрирование.

- `backend/` — Node.js/Express API.
- `frontend/` — веб-клиент на React.
- `android/` — нативный Android-клиент Dogma VPN (Kotlin + Compose).

## Android-клиент

Повторяет визуальный язык портала: тёмная тёплая палитра, золотой акцент,
Inter, панели. На главной — круг с логотипом приложения, который сам
является кнопкой подключения. Есть вход по логину/паролю и через Google
SSO, серверы Hysteria2, статистика, профиль и чат. Подключение использует
smart-подписку портала (`?format=singbox`), поэтому DNS и маршрутизация
берутся из веб-портала без потерь.

```bash
cd android
./gradlew assembleDebug
```

Подробности, сборка и ограничения: [android/README.md](android/README.md).
